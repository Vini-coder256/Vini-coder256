## 📌 Projeto em destaque

### 📅 Agenda Certa — Sistema de agendamentos

Aplicação web em desenvolvimento para ajudar microempreendedores e pequenos negócios a organizar agendamentos, serviços, profissionais e horários de atendimento.

**O que já desenvolvi:**

- Protótipo visual navegável.
- Interface de agendamento para clientes.
- Painel administrativo do empreendedor.
- Gerenciamento visual de serviços e profissionais.
- Configuração de horários e bloqueios.
- Planejamento da arquitetura de backend.

**Tecnologias:** React, TypeScript, Tailwind CSS e TanStack Start.

**Status atual:** protótipo v0.2 concluído e integração com Supabase em preparação. O sistema ainda utiliza dados de demonstração.
